# RX Toolhead Configurator V7

V7 fixes the interactive GLB selection preview, replaces the Universal/Common Parts set with the latest supplied files, makes Universal parts optional (enabled by default), constrains navigation zoom, and adds a Draco-enabled three-zone color customizer for the full RX V5.5 GLB.

Color zones: Main printed color, Red accent, RX logo (optional glow). Mechanical/electronic geometry is not intentionally recolored.
